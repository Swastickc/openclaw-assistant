Privacy Policy

Last updated: 27 October 2026

OpenClaw Assistant is a private, single-user automation tool operated by Swastick Chowdhury for personal use. It has exactly one user: its owner. It is not offered to the public and accepts no third-party sign-ups.

What information is accessed

With the owner's explicit consent, the tool accesses the owner's own Google account data: Gmail messages, Google Calendar events, Google Drive files, and Google Sheets spreadsheets. Access is granted through a Google OAuth client created and owned by the owner.

How it is used

The data is used solely to produce personal assistance for the owner — for example email summaries, schedule reminders, spending reports, and job-application preparation. Processing happens on the owner's own computer.

Storage

OAuth credentials and refresh tokens are stored locally on the owner's machine, in the macOS Keychain and local configuration files. Google user data is not copied to, or stored on, any third-party server by this tool.

Sharing and disclosure

No Google user data is sold, rented, transferred, or disclosed to any third party. Data is not used for advertising, and is not used to train generalised machine-learning models.

Limited Use

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

The owner may revoke the tool's access at any time at myaccount.google.com/permissions. Revoking access stops all further data access; locally stored tokens can then be deleted from the owner's machine, which removes any remaining stored credentials.
